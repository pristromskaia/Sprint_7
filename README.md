Создание курьера:
1. курьера можно создать;
2. нельзя создать двух одинаковых курьеров;
3. если одного из полей нет, запрос возвращает ошибку;
4. если создать пользователя с логином, который уже есть, возвращается ошибка.

Логин курьера
5. курьер может авторизоваться: для авторизации нужно передать все обязательные поля; успешный запрос возвращает id.
6. система вернёт ошибку, если неправильно указать логин или пароль;
7.если какого-то поля нет, запрос возвращает ошибку;
8.если авторизоваться под несуществующим пользователем, запрос возвращает ошибку;

Создание заказа
9.проверь, что, когда создаёшь заказ:
можно указать один из цветов — BLACK или GREY;
можно указать оба цвета;
можно совсем не указывать цвет;

Список заказов
10.проверь, что в тело ответа возвращается список заказов.
